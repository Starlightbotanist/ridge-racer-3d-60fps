Validation - Ridge Racer 3D USA 60 FPS variants

Target: USA revision 0, CTR-P-ARRE, title 0004000000035800.
Build identities are recorded in source/variants.json and MANIFEST.json.

Windows native headless Azahar; NVIDIA RTX 3050 Ti Laptop GPU, driver 546.30.
Standard Race, Category 4, Seacrest District, Fiera. Stereo disabled;
no texture filter; actual 4x internal resolution (1600x960 upper screen).

Each variant was cold booted separately on Vulkan and OpenGL using the
regular USA save. No emulator save state was loaded. Each run entered a
race through the menus, activated L+R nitrous with a private one-time
full-charge fixture, steered/braked, and verified that pausing stopped
the race clock. The charge fixture is not included in the patch.

Each timing sample spans 240 emulated display ticks. Cells show upper-
screen render count / race-clock advance. These are emulated timing
checks, not wall-clock performance benchmarks.

Version                     Bloom/glare   Motion blur   VK renders/clock  GL renders/clock
Standard (default)          Retained      Retained      240/+6000         240/+6000
No bloom                    Removed       Retained      240/+6000         240/+6000
No motion blur              Retained      Removed       240/+6000         239/+6000
No bloom or motion blur     Removed       Removed       240/+6000         239/+5950

The native nitrous-trigger entry was reached in every run. Blur-enabled
builds had two allocated blur quads and positive opacity during nitrous;
blur-removal builds had no allocated blur quads and zero opacity.
Executable hashes were verified after boot and after the race sample.
Captured frame sequences contain consecutive generations and both
render phases. The option matrix includes all four combinations.

Compiled ARM checks on the shared code:
- 20 interpolation/lifecycle groups, including 512 independent affine
  midpoint references across both native matrix-consumer layouts.
- 14 independent camera-pose cases, including distant positions, angle
  wrap, singular history, native endpoints and fallback recovery.
- 12 effect/badge consumer groups, including actual native matrix
  multiplication, both camera-copy formats, stale upload mirrors,
  pending deletion, hidden badges, worker bypass and pending uploads.
- Native scene animation stepping and ten VBlank wrap/reset cases.
- 18 executions comparing the relocated blur-alpha helper with AEONG's
  implementation at phases 0/1/2 and three opacity values.

Static and build checks:
- 49 linked sections with no overlaps or unexplained original branch,
  literal, address-construction or pointer references into reused code.
- Shared interpolation code occupies diagnostic overlays; native bloom
  and blur bodies are available independently of code placement.
- Variant images differ only at the selected effect callback entries.
- The queue crash correction, display-buffer rotation, live blur reset
  and protected callback/literal locations are retained.
- A clean source build reproduces all four checked-in patch pairs.
- IPS round trips, header identity and package file hashes are checked.

All variants use the same additional 200 KiB BSS reservation. The header
preserves the game's original CPU and memory-mode flags. The FPS counter
is removed, and the lower screen remains at its native 30 FPS.

Android and physical 3DS are untested with these variants. Coverage does
not include every course, vehicle, nitrous type, rare effect or a full
campaign. Original sprite artwork frame counts are unchanged.
